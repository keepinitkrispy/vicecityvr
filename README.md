# ViceCityVR clean restart
Independent package vcvr.clean. This is a routing diagnostic, not the completed 3D conversion. No automatic USB launch, Shizuku, accessibility service, native neural model, readback, or upscaling. Explicit Android single-app capture consent, HMD-only routing, 720p capture, frame-driven output capped at ~29 fps, stop on EGL error or display disconnect. The headset must already be in VR mode. Stop the old bridge before testing. Do not activate old depth processing to reproduce a whole-device lockup.
Build: bash build.sh. CI produces a signed debug APK.
Acceptance sequence: verify boot reason/crash logs first; test capture with depth absent; verify left/right alignment; then add lens mapping; add depth and upscale as isolated opt-in stages only after measuring stability. Two duplicated images are not actual stereo.
